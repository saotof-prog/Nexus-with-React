## 🚀 Démarrage rapide

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Builder pour la production
npm run build
```

---

## 🔌 Plugins disponibles

Ce template supporte deux plugins officiels selon tes préférences :

| Plugin | Transpileur | Idéal pour |
|--------|-------------|------------|
| [`@vitejs/plugin-react`](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) | [Oxc](https://oxc.rs) | Builds ultra-rapides |
| [`@vitejs/plugin-react-swc`](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) | [SWC](https://swc.rs/) | Compat maximale |

## 🧩 Aller plus loin

### TypeScript

Pour un projet en production, passe sur TypeScript avec des règles de lint avancées. Voir le [template TS officiel](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) et [`typescript-eslint`](https://typescript-eslint.io).

### React Compiler *(expérimental)*

Le React Compiler n'est pas activé par défaut car il peut ralentir le dev et le build. Pour l'activer : [documentation officielle](https://react.dev/learn/react-compiler/installation).
