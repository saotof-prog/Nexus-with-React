⚙️  REQUIRED CONFIGURATION

Get your Mailtrap credentials:
  1. Sign up at https://mailtrap.io (free)
  2. Create an inbox
  3. Copy SMTP credentials
  4. Update .env:

     SMTP_HOST=sandbox.smtp.mailtrap.io
     SMTP_PORT=2525
     SMTP_USER=<your-mailtrap-user>
     SMTP_PASSWORD=<your-mailtrap-password>

❓ HELP & TROUBLESHOOTING

  "Emails not sending?"
    → Check Mailtrap credentials in .env
    → Verify SMTP_HOST, SMTP_USER, SMTP_PASSWORD

  "Port 3000 already in use?"
    → Change PORT=3000 to PORT=3001 in .env
    → Or kill the process using that port

  "Frontend can't reach backend?"
    → Make sure both servers are running
    → Check console for CORS errors
    → Verify port numbers match

  "Token expired?"
    → Tokens are valid for 24 hours
    → User needs to request a new link
    → Delete nexus.db to reset database
